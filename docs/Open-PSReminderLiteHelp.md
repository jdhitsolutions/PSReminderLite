# Open-PSReminderLiteHelp

## SYNOPSIS

Open a PDF help file.

## SYNTAX

```yaml
Open-PSReminderLiteHelp [-AsMarkdown] [<CommonParameters>]
```

## DESCRIPTION

Open a PDF help file for the PSReminderLite module using the default associated application. As an alterative, you can view the project's README file as a Markdown document.

## EXAMPLES

### Example 1

```powershell
PS C:\> Open-PSReminderLiteHelp
```

This command opens the PDF help file for the PSReminderLite module.
